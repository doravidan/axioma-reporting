# גרסה v1.2.8 - תיקון דחוף להחזרות מדפי דיווח

## מה תוקן
- תיקון החזרה אחרי אישור דיווח ודחיית דיווח כאשר המערכת מותקנת תחת תיקייה/אפליקציה בשרת ולא בשורש האתר.
- תיקון החזרה אחרי העלאת אקסל או שגיאות אקסל כך שהמשתמש חוזר לדף הדיווח הקיים ולא לדף שלא קיים.
- תיקון קישור PDF שגיאות אקסל כך שייבנה לפי נתיב האפליקציה בשרת.
- הוספת fallback בטוח לקישור PDF שגיאות כדי למנוע חריגה בתרחישי בדיקה/שרת.

## בדיקות שבוצעו
- Build לפרויקט Web הסתיים בהצלחה.
- בדיקות העלאת אקסל שנכשלות עוברות בהצלחה.
- בדיקות ReportExcelImportService ו-DashboardFilterService עברו בהצלחה.
- בדיקה ידנית מקומית: POST להעלאת אקסל ללא קובץ מחזיר לדף הדיווח הקיים עם הודעת שגיאה ולא ל-404.

## התקנה בשרת
1. לעצור את האתר/IIS Application Pool.
2. לגבות את תיקיית האתר ואת בסיס הנתונים.
3. לפרוס את תוכן `publish` מתוך:
   `AxiomaReporting-Delivery-v1.2.8.zip`
4. לוודא ש-`appsettings.Production.json` / משתני הסביבה של השרת נשארים עם מחרוזת החיבור הנכונה.
5. להריץ מיגרציות אם קיימות מיגרציות חדשות שלא הותקנו בשרת:
   `dotnet ef database update --project src/AxiomaReporting.Infrastructure --startup-project src/AxiomaReporting.Web`
6. להפעיל את האתר/IIS Application Pool.
7. לבדוק: העלאת אקסל עם שגיאות, דחיית דיווח, אישור דיווח.
