# גרסה v1.2.9 - תיקון נתיבי דוח תחת PathBase בשרת

## מה תוקן
- הוחלפו קריאות JavaScript קשיחות ל-`/Report/...` בדף הדיווח לנתיבים שנוצרים על ידי ASP.NET:
  - טעינת שורת דיווח לעריכה.
  - שמירת תא/שורה.
  - עריכה בשורת פירוט.
  - שכפול שורה.
  - מחיקת שורה.
  - העלאת מסמך לדיווח.
  - מחיקת מסמך.
- התיקון משלים את v1.2.8 כדי שגם פעולות צד-לקוח יעבדו כאשר האתר מותקן תחת נתיב אפליקציה בשרת ולא בשורש האתר.
- ההחזרות אחרי העלאת אקסל, אישור ודחיית דיווח נשארות עם שמירת `PathBase`.

## בדיקות שבוצעו
- Build לפרויקט Web עבר בהצלחה.
- בדיקות ממוקדות עברו:
  - `ReportExcelImportServiceTests`
  - `DashboardFilterServiceTests`
  - בדיקות `UploadExcel` מתוך `ReportControllerGapsTests`
- בדיקה בקוד: לא נשארו קריאות פעילות מסוג `fetch('/Report/...')` או `fetch("/Report/...")`.
- בדיקה מקומית בדף הדיווח: הדף נטען, וה־JavaScript מכיל `reportUrls` שנוצרים על ידי השרת.

## התקנה בשרת
1. לעצור את האתר או את ה-IIS Application Pool.
2. לגבות את תיקיית האתר ואת בסיס הנתונים.
3. לפרוס את תוכן תיקיית `publish` מתוך:
   `AxiomaReporting-Delivery-v1.2.9.zip`
4. לשמור/להחזיר את קובץ ההגדרות של השרת אם הוא לא חלק מהפריסה.
5. להריץ מיגרציות רק אם קיימות מיגרציות חדשות שלא הורצו בשרת.
6. להפעיל את האתר/IIS Application Pool.
7. לבדוק בשרת:
   - העלאת אקסל עם שגיאות חוזרת לדף הדיווח ומציגה שגיאות + PDF.
   - אישור דיווח חוזר לדשבורד/מסך הסיכום הנכון.
   - דחיית דיווח חוזרת לדשבורד/מסך הסיכום הנכון.
   - עריכת שורה/תא בדף הדיווח עובדת בלי שגיאת 404.
